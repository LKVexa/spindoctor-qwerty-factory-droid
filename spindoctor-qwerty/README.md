# spindoctor-qwerty (Factory Droid plugin)

SpinDoctor 3.1.2 quantum-circuit **simulator** (classical FP64 on your computer, not a quantum computer) as a Droid plugin:
skill `spindoctor-qwerty`, droid `qwerty-helper`, commands `/qwerty-functions`, `/qwerty-run`, `/qwerty-preset`, `/qwerty-folder`,
`/qwerty-theory`, and the MCP server `spindoctor-qwerty` (6 `spindoctor_*` tools, Python 3.8+, standard library only).

Install it from its marketplace: `droid plugin marketplace add LKVexa/spindoctor-qwerty-factory-droid`, then
`droid plugin install spindoctor-qwerty@spindoctor-qwerty-factory-droid --scope user`. Full documentation:
https://github.com/LKVexa/spindoctor-qwerty-factory-droid
